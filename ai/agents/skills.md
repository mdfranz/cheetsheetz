# Foundations
- [spec](https://agentskills.io/specification) - Open specification for defining agent skills and capabilities.
- [skills](https://github.com/anthropics/skills) - Official repository of agent skills by Anthropic.

# Links 
- [awesome-llm-skills](https://github.com/Prat011/awesome-llm-skills) - Curated list of skills for LLM agents.
- [awesome-agent-skills](https://github.com/heilcheng/awesome-agent-skills) - Collection of frameworks and tools for agent skill development.

# Tools
- [SkillOpt](https://github.com/microsoft/SkillOpt) - Text-space optimizer for training reusable natural-language skills for LLM agents.
- [Skilz](https://pub.spillwave.com/skilz-the-universal-package-manager-for-ai-skills-dac41e6879ec) - Universal package manager for AI skills.
- [agent_skills_directory](https://github.com/dmgrok/agent_skills_directory) - Directory of reusable skills and plugins for AI agents.
