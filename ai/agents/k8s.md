# Platforms for Deployment
- [agent substrate](https://github.com/agent-substrate/substrate) - Kubernetes-native substrate for running and managing autonomous AI agent workloads.
- [ark](https://github.com/mckinsey/agents-at-scale-ark) - McKinsey framework for orchestrating and scaling enterprise AI agents on Kubernetes.
- [kagent](https://kagent.dev/) - Cloud-native declarative agent operator for Kubernetes ([docs](https://kagent.dev/docs/kagent), [code](https://github.com/kagent-dev/kagent)).
- [agent-runtime-operator](https://github.com/agentic-layer/agent-runtime-operator) - Kubernetes operator managing lifecycle, runtimes, and execution environments for AI agents.
- [agent-sandbox](https://github.com/kubernetes-sigs/agent-sandbox) - Kubernetes SIG project providing isolated runtime sandboxes for untrusted agent execution.
- [openshell](https://github.com/nvidia/openshell) - NVIDIA environment using k3s under the hood for agent sandbox execution (see [sandboxes](../sandbox.md)).
- [kaos](https://github.com/axsaucedo/kaos) - Kubernetes Agent Orchestration System for deploying and managing agent workloads.
